Getting started

Install the server on Windows

Set up your own Haven chat server on a Windows PC in a few minutes.

  1. Go to haven-app.com, open Download, and download the server .zip.
  2. Unzip it and double-click Start Haven.bat.
  3. If Node.js isn't installed, it offers to install it for you. Say yes, then run Start Haven.bat again.
  4. The first run downloads what Haven needs and makes a security certificate. When it says "Haven is LIVE", it's running. Keep that window open.
  5. Open https://localhost:3000 in your browser. The security warning is expected because Haven made its own certificate: click Advanced, then Proceed.
  6. Click Register and create an account named admin. That account is the server's admin.

Next: the First login video covers naming your server and making channels.

Install the server on Linux

Set up your own Haven chat server on a Linux machine, no Docker needed. Shown on a fresh Ubuntu 24.04.

Commands: sudo apt update sudo apt install -y curl git curl -fsSL https://deb.nodesource.com/setup_26.x | sudo -E bash - sudo apt install -y nodejs git clone https://github.com/ancsemi/Haven.git cd Haven chmod +x start.sh && ./start.sh

When it says Haven is LIVE, open https://localhost:3000 (or https://YOUR_SERVER_IP:3000 from another computer). The security warning is expected because Haven made its own certificate: click Advanced, then Proceed. Register an account named admin; that account runs the server.

Haven needs Node.js 22 or newer. The nodejs package in Ubuntu's own repositories is older, which is why this uses NodeSource. Prefer Docker? There's a separate video for that.

Install with Docker

Run your own Haven chat server with one Docker command. Works on Linux, a NAS, or anywhere Docker runs.

Start it: docker run -d --name haven -p 3000:3000 -v haven_data:/data --restart unless-stopped ghcr.io/ancsemi/haven:latest

Then open https://localhost:3000 (or https://YOUR_SERVER_IP:3000). The security warning is expected because Haven made its own certificate: click Advanced, then Proceed. Register an account named admin; that account runs the server.

Update it later: docker pull ghcr.io/ancsemi/haven:latest docker rm -f haven then run the same docker run command again. Your messages and settings stay in the haven_data volume.

Prefer Docker Compose? The repository has a ready docker-compose.yml: git clone https://github.com/ancsemi/Haven.git, cd Haven, docker compose up -d. On Podman or a NAS, see the Docker section of the setup guide.

First login: name, first channel and icon

What to do the first time you sign in to your new Haven server as the admin.

  1. The setup window asks for your server's name. Type it and click Next.
  2. Name your first channel and click Create & Continue.
  3. Click Next past Internet Access (there's a separate video on letting friends in), then Get Started.
  4. For a server icon, open Settings, go to the Admin tab. Branding is on the Server page.
  5. Choose an image and click Upload. It shows up right away.
  6. Add a welcome message if you like, then click Save Settings.
